**PDFViewer.swift**

This SwiftUI code defines a `PDFKitView` struct that displays a PDF document using `PDFKit`. It utilizes `UIViewRepresentable` to integrate the `PDFView` from UIKit into SwiftUI. The view automatically scales the PDF and displays it in single-page continuous mode.  A notification observer enables an "accept" button when the user reaches the last page of the PDF.  The `document` property is a binding, allowing updates to the PDF document to be reflected in the view.
