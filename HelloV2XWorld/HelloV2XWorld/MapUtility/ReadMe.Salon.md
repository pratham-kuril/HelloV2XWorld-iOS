**CamAnnotation.swift**

This Swift code defines `CamAnnotation`, a class representing map annotations for Cooperative Awareness Messages (CAMs). It conforms to `MKAnnotation` for display on MapKit maps. `CamAnnotation` stores coordinates, an ID, the CAM data (`V2XCAM`), and computed properties for the title, subtitle, and image. The `getCamIcon()` method returns different icons based on whether the annotation represents the user's current location or another CAM.  `getTitleText()` and `getSubtitleText()` generate informative strings displaying station ID, type, speed, and heading derived from the `V2XCAM` data.


**MapView.swift**

This Swift code defines a `MapView` struct that displays a map with custom annotations for V2X (Vehicle-to-Everything) CAM (Cooperative Awareness Message) data. It uses `MKMapView` and integrates with the Vodafone V2X SDK.  The map updates its region based on user location and displays CAM messages as annotations.  Annotations are dynamically added, updated, and removed based on the incoming CAM data.  The map's zoom level is controlled by an `EnvironmentObject` called `ZoomSettings`.  The code also handles map camera adjustments for smooth transitions during location updates and annotation rotations based on vehicle heading.
